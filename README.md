# Mini NPU Simulator

## 1. 실행 방법
```
python3 main.py
```
프로그램 실행 후 아래 중 선택한다:

1. 사용자 입력 (3x3)
2. data.json 분석

- 1번 모드: 직접 필터와 패턴 입력 후 결과 확인  
- 2번 모드: data.json 파일을 기반으로 일괄 분석 수행  

---

## 2. 구현 요약

### 2.1 MAC 연산 (Multiply-Accumulate)

입력 패턴과 필터를 동일한 위치에서 곱한 뒤, 그 값을 모두 더하여 점수를 계산하는 방식으로 구현하였다.
```
total += pattern[i][j] * filter[i][j]
```
이 연산은 2중 반복문을 사용하여 구현하였으며, 외부 라이브러리는 사용하지 않았다.

---

### 2.2 판정 로직 및 epsilon 적용

부동소수점 연산 특성상, 두 점수가 동일하더라도 미세한 차이가 발생할 수 있다.

예:  
```
0.9000000000000000 != 0.8999999999999999
```
이를 해결하기 위해 epsilon 기반 비교를 사용하였다.
```
abs(score_a - score_b) < 1e-9
```
- 차이가 epsilon보다 작으면 → UNDECIDED  
- 그렇지 않으면 → 더 큰 값을 가진 필터 선택  

---

### 2.3 라벨 정규화 (Normalization)

data.json의 라벨은 다양한 형태로 존재할 수 있기 때문에 내부적으로 표준 라벨로 변환하였다.

"+", "cross" → Cross  
"x" → X  

이를 통해 비교 시 일관성을 유지하였다.

---

### 2.4 JSON 데이터 처리

- patterns의 key에서 size 추출 (예: size_13_1 → 13)  
- 해당 size에 맞는 필터 선택  
- 입력 데이터와 필터의 크기 일치 여부 검증  
- 각 케이스별로 MAC 연산 → 판정 → PASS/FAIL 출력  

---

### 2.5 성능 분석

각 크기별로 MAC 연산을 반복 수행하여 평균 실행 시간을 측정하였다.

- 측정 대상: MAC 연산 함수만  
- 반복 횟수: 10회 이상  
- 단위: ms (밀리초)  

출력 항목:  
크기(NxN) / 평균 시간(ms) / 연산 횟수(N²)

---

## 3. 결과 리포트

### 3.1 실패 케이스 분석

본 프로젝트에서는 data.json 기반 테스트를 수행한 결과,
총 3개의 테스트 케이스 중 2개는 PASS, 1개는 FAIL로 나타났다.

FAIL 케이스 분석 결과, 해당 문제는 데이터/스키마 오류에 해당한다.

구체적으로 size_3_3 케이스는 입력 패턴이 Cross 형태임에도 불구하고
expected 값이 "x"로 설정되어 있어, 프로그램의 판정 결과와
의도적으로 불일치하도록 구성된 데이터이다.

이 경우 MAC 연산 결과는 Cross 필터에서 더 높은 점수를 가지므로
정상적으로 Cross로 판정되지만, expected 값과 비교 시 FAIL이 발생한다.

이러한 사례를 통해 프로그램의 판정 로직이 정상적으로 동작하고 있음을
확인할 수 있으며, FAIL의 원인이 로직이 아닌 데이터 설정에 있음을
명확히 구분할 수 있다.

---

### 3.2 시간 복잡도 분석

MAC 연산은 2중 반복문 구조로 이루어져 있다.
```
for i in range(N):  
    for j in range(N):  
```
따라서 전체 연산 횟수는 다음과 같다:

N × N = N²  

즉, 시간 복잡도는 다음과 같다:

O(N²)

---

### 3.3 성능 측정 결과 해석

패턴 크기가 증가함에 따라 연산 횟수(N²)가 증가하고, 이에 따라 실행 시간 또한 증가하는 경향을 확인할 수 있다.

특히 작은 크기에서는 실행 시간이 매우 짧기 때문에 측정 오차가 상대적으로 크게 나타날 수 있으나, 크기가 커질수록 증가 추세가 명확하게 나타난다.

## 4. 프로젝트 구조
```

├── main.py                # 프로그램 시작 / 흐름 제어
├── data.json  

├── core/  
│   ├── mac.py             # MAC 연산
│   ├── judge.py           # 점수 비교 / 판정
│   └── normalize.py       # 라벨 정규화

├── input_output/  
│   ├── input_handler.py   # 사용자 입력 (3x3) 처리
│   └── json_loader.py     # data.json 읽기 / 검증

├── analysis/  
│   └── performance.py     # 성능 측정
```

## 5. 결론

본 프로젝트를 통해 MAC 연산의 원리와 AI 모델에서의 활용 방식을 이해할 수 있었으며, 데이터 처리, 수치 비교, 성능 분석까지 포함한 전체적인 흐름을 경험할 수 있었다.

특히 부동소수점 비교 문제와 데이터 정규화의 중요성을 확인할 수 있었으며, 입력 크기에 따른 연산 시간 증가를 통해 시간 복잡도 O(N²)을 실험적으로 검증할 수 있었다.
